# SafeRoute 3D — Ön Yüz

Bu dizin **Faz 5** (Profesyonel ön yüz ve etkileşimli analiz ekranları) kapsamında oluşturulacaktır. Faz 1'de bilinçli olarak boş bırakılmıştır.

Planlanan teknolojiler (`PROJECT_SPEC.md` §10): React, TypeScript, Vite, Tailwind CSS, shadcn/ui, MapLibre GL JS, Three.js, Recharts veya Plotly.

Ön yüz yalnızca arka uçtan gelen **gerçek** analiz sonuçlarını gösterecektir; statik veya uydurma metrikler kullanılmaz.
